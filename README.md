# Laser Harp

Designed a functional laser harp that turns beam breaks into real-time MIDI notes.

https://github.com/user-attachments/assets/b7bedd5a-9a4b-4dd0-8b36-9d9033d4c819

## Highlights

- 6-beam laser harp that turns beam breaks into real-time MIDI notes
- Replaced photoresistors (20–100 ms response time) with PT334-6C phototransistors to catch a ~30 ms hand pass
- Two-stage sensor tunnels (8 mm / 5.2 mm bore) to eliminate ambient-light false triggers
- Switched to an ATmega32U4 Pro Micro for native USB MIDI, removing the Hairless MIDI bridge and IAC Driver dependency
- Class 3R-safe (≤5 mW) instrument built for ~$100 CAD
